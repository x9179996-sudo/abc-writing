# ABC 寫字本（一年級英語字母大小寫書寫練習）正式版

專為台灣小學一年級學生設計的英文字母筆順書寫互動練習網頁與教學資源套件。

- 🌐 **線上體驗網址**：https://x9179996-sudo.github.io/abc-writing/
- 📋 **52 字母筆順審閱頁**：https://x9179996-sudo.github.io/abc-writing/overview.html
- 📄 **可列印 A4 練習單 (全 26 頁 PDF)**：[ABC寫字本_A4練習單_全26張.pdf](ABC寫字本_A4練習單_全26張.pdf)

## 功能特色

1. **26 組大小寫字母全開放**：
   - 包含 A–Z 共 52 個字母。
   - 字母牆全開放練習，收集星星進度。
   - 26 格動物貼紙本（使用相容性高的 Unicode 6–10 動物 emoji，舊型手機亦能正常顯示）。
   - 本地儲存進度（`localStorage` key：`abc-writing-v1`）。

2. **符合英語老師標準字形與筆順規範**：
   - 四線三格標準座標系：第 1 線 y=0、第 2 線 y=100、第 3 線（實線基線）y=200、第 4 線 y=300。
   - 大寫字母高度 200（y=0 至 y=200）；大寫 `I` 上下帶橫槓；大寫 `J` 頂部帶橫槓。
   - 小寫字母身體位於 2–3 線（y=100 至 y=200）；上伸字（b, d, f, h, k, l）頂至 y=0；`t` 頂端止於 y=50。
   - 下伸字（g, j, p, q, y）延伸至 y≈295；`q` 直尾不帶鉤；`y` 兩筆直線。
   - 小寫 `i`、`j` 支援「點」型筆畫判定（半徑與微動判定）。
   - 小寫 `k` 斜線交點於 y≈150。
   - 13 個常見寫法差異字母標記 `review: true`（大寫 B, E, G, I, J, M, R, T；小寫 a, f, k, t, y），審閱頁加框標註。

3. **四段漸進式練習關卡**：
   - 第 0 關：看筆順（動態描繪示範）
   - 第 1 關：描一描（灰色粗軌道輔助）
   - 第 2 關：虛線寫（虛線輔助）
   - 第 3 關：自己寫（空白四線格，僅標記起筆橘點）

4. **老師示範模式**：
   - 支援 26 組字母切換、大小寫切換。
   - 單筆逐步播放、完整連續播放、虛線字切換、電子白板筆手寫與即時清除功能。

5. **A4 練習單整合**：
   - 網頁內嵌預覽與直接呼叫 `window.print()` 列印功能，首頁支援「全部 26 張」或指定單組列印。
   - 附帶 Playwright 自動化產生高品質向量 PDF 腳本。

## 怎麼更新與維護

### 1. 修改字母筆順或字形
- 筆畫資料定義於 `index.html` 中的 `const LET = { ... }` 物件。
- 如有修改，請同步更新 `overview.html` 中相對應的 `const LET` 區塊。

### 2. 執行判斷邏輯測試
於終端機執行：
```bash
node tools/test_judge.js
```
測試將檢驗 52 個字母共 98 個筆畫：
- 正向取樣點判定必須為通過（`ok: true`）。
- 反向取樣點判定必須為失敗（`ok: false`）。
- 點型筆畫在目標位置判定必須為通過，偏移 50 單位判定必須為失敗。

### 3. 重新產出 A4 練習單 PDF
```bash
node tools/make_pdf.js
```
將會自動啟動 Playwright 渲染並輸出 `ABC寫字本_A4練習單_全26張.pdf`（共 26 頁）。

### 4. 重新產出驗收截圖與版面檢驗
```bash
node tools/verify_and_screenshot.js
```
